# 媒体库工作台

## 兼容与启用

继续复用原配置数据库和 `/media` 元数据路径，原视频源、筛选规则与下载状态保持不变。新配置字段都有默认值。无需批量重置已有视频。

在「网盘分流 → CloudDrive2 · 115」保存 CD2 地址、API 令牌及保存根目录。已连接 115 时可直接检查连接；如需新增账号，可使用 115 扫码入口，CD2 令牌需要账号管理权限。

填写「STRM 播放服务地址」，例如 `https://bili.example.com`。这是 Emby/播放器可访问的 bili-sync 地址。新视频上传到云端并确认完成后，程序记录准确路径，在本地元数据旁生成同名 STRM。无需扫描整棵目录。

STRM 使用每个文件独立的随机播放令牌，通过 bili-sync 和 CD2 解析当前下载位置并传输文件，支持 Range 请求。bili-sync 和 CD2 都需要保持运行。STRM 中不包含 B 站凭据或 CD2 API 令牌；请不要公开分享 STRM 内容。

写入 STRM 失败时，已确认的上传记录仍保留。重试通过记录补写，不重复下载或上传。已有云端视频可在媒体库中手动选择「补写 STRM」，只定位所选文件。启用本服务 STRM 后停止发送专用 MediaIndex 扫描通知，通用通知器保留。

## 画质管理

进入视频源，点击收藏夹/投稿/合集名称即可查看视频。页面读取数据库及本地保存记录，不主动访问 B 站或遍历网盘。

1. 筛选并选择最多 25 个分 P。
2. 点击「对比 B 站画质」。优先读取本地记录；旧视频缺少记录时，只读取所选文件的实际视频信息，再获取当前账号可访问的 B 站视频流。
3. 选择标记为可升级的视频，点击「升级所选画质」。程序重新核对候选流，下载到临时目录，验证分辨率、时长、编码、帧率和码率，再切换到新版本。

不同编码的码率不直接比较；仅画质标签提高不能证明实际画质提高。验证不通过时保留原视频。云端升级使用独立版本文件，STRM 的稳定地址切换到新版本；旧文件和旧记录保留在云端及配置目录，暂不自动清理。升级仍需要本地临时空间容纳候选视频。

画质任务与普通下载互斥，每个分 P 之间至少等待两秒。检测到 B 站风控后停止当前批次。逐文件比较记录保存在配置目录 `quality/`，上传记录保存在 `library/`，应随数据库一起备份。

## 调度与界面

- 快捷订阅会打开完整配置表单，保存时一起提交目录、筛选规则、画质及启用状态。
- 用户投稿支持 UID 和 UP 名称搜索；同名账号请核对 UID。
- 自动刷新窗口使用容器本地时区，支持跨午夜。起止留空或相同表示全天。
- 随机间隙在每次自动触发后执行，等待结束再次检查时间窗口。手动刷新不受窗口及随机间隙限制。
- 外观配色保存在当前浏览器，支持海盐蓝、鸢尾紫、蔷薇红、琥珀橙、湖水青和石墨灰。

## 当前验证范围

开发分支包含前后端实现，仍需完成后端 CI、真实 B 站搜索、CD2 单文件读取和播放器联调。测试期间不替换生产容器，也不批量升级既有视频。
