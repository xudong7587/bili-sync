# 媒体库工作台

## 兼容与启用

继续复用原配置数据库和 `/media` 元数据路径，原视频源、筛选规则与下载状态保持不变。新配置字段都有默认值。无需批量重置已有视频。

在「网盘分流 → CloudDrive2 · 115」选择保存方式：本地模式将视频和元数据一起保存到原订阅目录，不使用 CD2，也不应用旧的 `/video` 分离映射；网盘模式直传 115。切换只影响后续保存，不迁移旧文件。旧配置缺少 `storage_mode` 时继续按原 CD2/挂载配置运行。已有网盘文件的播放仍可使用保留的 CD2 连接信息。

网盘模式需保存 CD2 地址、API 令牌及保存根目录。CD2 仅通过地址和 API 令牌接入，使用已有的 115 上传目标。

独立 115 扫码登录入口暂时隐藏。上传和播放统一使用 CD2 已登录的 115 账号，不读取或导出其 Cookie，也不要求再次扫码。已有的独立 115 凭据不会影响当前播放链路。

CD2 区域显示连接状态并提供测试按钮。测试直接使用当前表单内容，不保存配置；修改后测试通过仍需点「保存配置」。前端认证状态仅显示在 B 站账号页面。

填写「STRM 播放服务地址」，例如 `https://bili.example.com`。这是 Emby/播放器可访问的 bili-sync 地址。新视频上传到云端并确认完成后，程序记录准确路径，在本地元数据旁生成同名 STRM。无需扫描整棵目录。

STRM 使用每个文件独立的随机播放令牌，通过 bili-sync 解析并传输文件，支持 Range 请求。上传时保存准确云端路径，播放时向 CD2 请求该文件的下载入口，再由 bili-sync 转发媒体数据。bili-sync 和 CD2 均需保持运行。STRM 只包含稳定的播放 URL；画质、大小、时长保存在本地记录，过期的网盘直链不写入 STRM。STRM 中不包含 B 站凭据或 CD2 API 令牌；请不要公开分享 STRM 内容。

写入 STRM 失败时，已确认的上传记录仍保留。重试先核对记录指向的云端文件确实存在、大小相符且不在上传中，再补写 STRM，不重复下载或上传。云端文件缺失时明确报错，不能仅凭本地记录标记成功；需要重新下载时使用「清空重置」。已有云端视频可在媒体库中手动选择「补写 STRM」，只定位所选文件。专用 MediaIndex 设置已隐藏，旧 URL/令牌仅保留用于配置兼容；新增 `media_index_webhook_enabled` 默认为 false，旧配置不会自动继续发送扫描通知。通用通知器保留。

## 画质管理

进入视频源，点击收藏夹/投稿/合集名称即可查看视频。页面读取数据库及本地保存记录，不主动访问 B 站或遍历网盘。

1. 筛选并选择最多 25 个分 P。
2. 点击「对比 B 站画质」。优先读取本地记录；旧视频缺少记录时，只读取所选文件的实际视频信息，再获取当前账号可访问的 B 站视频流。
3. 选择标记为可升级的视频，点击「升级所选画质」。程序重新核对候选流，下载到临时目录，验证分辨率、时长、编码、帧率和码率，再切换到新版本。

不同编码的码率不直接比较；仅画质标签提高不能证明实际画质提高。验证不通过时保留原视频。云端升级使用独立版本文件，STRM 的稳定地址切换到新版本；旧文件和旧记录保留在云端及配置目录，暂不自动清理。本地升级先准备新文件及旧版本备份，再原子替换视频路径。配置目录记录提交事务；中途退出后，下次启动会恢复旧文件和对应画质记录。旧版本备份记录指向实际备份文件。升级需要本地空间容纳候选文件及提交副本；不支持硬链接的文件系统还需要旧版本备份空间。

画质任务与普通下载互斥，每个分 P 之间至少等待两秒。检测到 B 站风控后停止当前批次。逐文件比较记录保存在配置目录 `quality/`，上传记录保存在 `library/`，应随数据库一起备份。

## 调度与界面

- 快捷订阅会打开完整配置表单，保存时一起提交目录、筛选规则、画质及启用状态。
- 用户投稿支持 UID 和 UP 名称搜索；同名账号请核对 UID。
- 自动刷新窗口使用容器本地时区，支持跨午夜。起止留空或相同表示全天。
- 随机间隙在每次自动触发后执行，等待结束再次检查时间窗口。修改配置会立即取消旧的随机等待。手动刷新不受窗口及随机间隙限制。
- 外观配色保存在当前浏览器，默认哔哩粉，另支持海盐蓝、鸢尾紫、蔷薇红、琥珀橙、湖水青和石墨灰。

## 当前验证范围

已验证 NAS 上 CD2 单文件定位及 Range 请求（206，仅读取 16 字节）。前端类型检查、Lint 和构建已运行；开发分支 CI 持续校验。真实 B 站搜索、实际画质升级与 Emby 完整播放仍需账号联调。独立 115 登录不作为当前版本的启用步骤。测试期间不替换生产容器，也不批量升级既有视频。

## 仪表盘

- CPU 与内存合并为双线图；下载速度由实际接收的媒体字节数计算，每两秒更新。
- 视频分布饼图统计本地保存记录中的当前视频，区分本地与 115，不遍历网盘；旧视频、升级备份及其他网盘文件不在统计范围。
- 原视频管理嵌入仪表盘下方，保留状态、时间、有效性、来源筛选和批量操作；支持来源分栏和卡片/横幅/表格。表格提供当前页多选、窄幅封面、截断标题、入库时间、BV/收藏时间、UP 主和任务状态；表头支持标题、入库时间、UP 主全量排序，换页/排序后清空勾选。入库时间指首次进入 bili-sync 数据库，不代表 Emby 入库时间。
- 卡片百分比表示处理步骤完成比例，不是下载字节进度；鼠标停留可查看具体步骤状态。
- 右上角日志按钮打开弹窗；保留最近 500 条，支持级别筛选和暂停。
